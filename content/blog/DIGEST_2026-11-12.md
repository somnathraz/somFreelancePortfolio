**Title:** This week: five bugs hiding in a URL shortener

**Five bugs hiding in a URL shortener (and the fix for each)**
"Design a URL shortener" usually gets three boxes. Five bugs sit inside them: ID collisions, stale redirects after an edit, a click counter that slows every redirect, a custom-alias race, and a nightly cleanup that deletes nothing. Each one is a runnable trap with the fix and a test against real Postgres with 50 concurrent users, and two of the five share the same read-decide-write gap as the double-booked seat.
