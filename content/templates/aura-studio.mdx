Aura Studio is a standalone luxury headphone concept. Built for brands that want a cinematic product site — not a brochure with a stock render.

## Tech stack

- **Next.js App Router** — server route composition, metadata, and static sections as server components
- **TypeScript** — shared product and finish domain types
- **React Three Fiber + Three.js** — procedural headphone model in an isolated WebGL renderer (dynamically imported, SSR disabled)
- **Motion** — entrance timelines, scroll chapters, and particle motion
- **Google Fonts** — optional external request with system-font fallbacks

## Project structure

```text
src/
  app/                   Route composition, metadata, global design system
  components/
    sections/            Page-level story and configurator sections
    product/             Lazy-loaded WebGL scene and procedural model
    ui/                  Shared presentation primitives
  hooks/                 Reusable browser behavior
  lib/                   Product catalog and formatting utilities
  types/                 Shared domain types
public/                  Static assets
```

Change finishes and price in `src/lib/product.ts`. Edit model geometry in `src/components/product/headphones.tsx`. Global tokens live in `src/app/globals.css`.

## Experience highlights

- Synchronized form / sound / fit chapters with projected 3D callouts
- Live finish switching without page reloads
- Scroll progress stored in a ref to avoid React rerenders on every frame
- Sound visualization is illustrative; the audible demo is stereo panning (not Dolby / head-tracked spatial)

## Scope

Aura is a fictional brand. Specs and pricing are illustrative. No checkout, payments, authentication, or backend. The 3D model is procedural — not manufactured CAD. WebGL is required for the interactive model.
