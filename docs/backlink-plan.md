# Backlink plan (competitor gap analysis)

Data: SEMrush Backlink Gap and Backlink Analytics via ToolzBuy, pulled 2026-10-30.

Competitors compared (they rank top 10 for our target keywords):

- MVP / React / white label: freshcodeit.com, e2msolutions.com, simpalm.com (7,803 gap domains)
- MVP / React / white label: ventionteams.com, devoxsoftware.com, uplers.com (15,948 gap domains)

Gap domains = sites linking to at least one competitor but not to somanathkhadanga.com. AS = SEMrush Authority Score.

## Our current profile

- Authority Score 2. 1.6K referring domains, 1.7K backlinks, up ~660% this year.
- SEMrush network graph: "Dangerous". Sampled links are auto-generated SEO-checker and "backlink generator" sites (autobacklinkbot.info, aibacklinkgenerator.online, dacheckeronline.online, 7-seo.info, allbacklinkschecker.site and similar). These are created automatically for most domains, not something we did.
- Search Console shows no manual action. Google says it ignores this kind of link, so a disavow file is not needed now. Revisit only if a manual action appears or rankings drop sharply.
- Real links today: paperchaiapp.com and a few others. Effectively we start from zero.

## Tier 4: communities and own assets (weekly)

- Cross-post selected blog posts to dev.to, Hashnode and Medium with a canonical link back to the original.
- Answer founder and agency questions on Reddit (r/startups, r/SaaS, r/webdev, r/agency), Indie Hackers and Quora (Quora ranks for "white label web design").
- Launch Labs / Traps and the templates on Product Hunt and Hacker News (Show HN); tools earn links more easily than service pages.
- GitHub: link the site from the profile and from READMEs of public templates.
- PaperChai (paperchaiapp.com) already links; add a "built by" link on any other shipped product with client permission.

## Skip

- Press release wires (prnewswire, marketersmedia, press.farm): paid and nofollow; little SEO value.
- Link generators and "free backlink" sites (the ones already pointing at us).
- Gap domains that link to competitors because of their own scale: yahoo.com, bing.com, forbes.com, substack.com (unless writing there).
